# rigstats-backend

Shared library used by both binaries (`rigstats`, `rigstats-wallpaper`). Domain logic belongs here — `src-egui/` is UI and wiring. Full module detail: `docs/architecture.md` ("Backend Modules").

- **`stats.rs`** — `StatsPayload` + sub-structs: the session-recording row shape (built from `PollStats` in `poll.rs`); `DiskKind`
- **`hardware.rs`** — WMI hardware detection (PowerShell only when WMI fails): GPU names, RAM, disk, system brand, model, motherboard, ping target, battery. Typed `query::<T>()` structs need a `#[serde(rename = "Win32_…")]` container rename (#198, guarded by `wmi_classes_tests`)
- **`lhm.rs`** — named pipe client → `LhmData`; `select_gpu_idx` (preferred → highest VRAM → load tie-break), `normalize_gpu_name`/`gpu_names_match` (WMI/LHM-tolerant name matching)
- **`process_list.rs`** — the running processes from one `NtQuerySystemInformation(SystemProcessInformation)` call per tick (#463): `ProcessReader::read` → `RawProcess` totals, pure `parse` (every offset, length and name pointer checked against the buffer — never reads outside it), `UsageTracker::update` → per-tick `ProcessUsage` (CPU % of the machine, I/O bytes). Feeds the Processes panel, GPU Apps names and disk read/write in `poll.rs`. Not sysinfo: its refresh (~80 % of the poll loop's CPU) also opened every process for five more calls; this halves it (~13 M cycles a tick against ~27 M), the call itself is most of what is left
- **`lhm_process.rs`** — connection state tracking (connect/disconnect logging, 30 s throttle)
- **`pipe_server.rs`** — `is_service_pipe`: both pipe clients only accept a server running in session 0 (the service), so another process that took the pipe name is ignored; debug builds accept any server (dev sidecar). The service side: `sensor-sidecar/Control/DataDirectory.cs` locks `%ProgramData%\se.codeby.rigstats` to SYSTEM/Administrators before anything is read from it
- **`control.rs`** — Control Center pipe client (`\\.\pipe\rigstats-control`, duplex): `control_task` → `ControlState` (capabilities, profiles, live `fan_duty`, `fan_identified`, safety trips, running `preview`, crash-guard notice); `ControlCmd`; typed fan, CPU-limit, Curve Optimizer, GPU and lighting profile/capability structs. Service side: `sensor-sidecar/Control/CLAUDE.md`.
- **`logging.rs`** — session-based CSV stats logging: `start_session`/`end_session`, `append_stats_row`, `load_sessions`/`rename_session`/`set_session_pinned`/`delete_session`, `prune_old_sessions`, `reconcile_sessions_on_startup`; `ActiveSession` — the poll loop asks every second, the index is parsed again only when its modified time or size changed (#466). Session index (`rigstats-sessions.json`) writes are guarded by a cross-process file lock (`SessionsLock`) and mirrored to a `.bak` for corruption recovery.
- **`microphone.rs`** — the microphone's mute through Windows (#425): `current` / `set_muted` / `toggle` on the default *communications* capture endpoint (`IAudioEndpointVolume`, COM via winapi, same shape as `desktop_background`). Vendor-neutral and writes nothing to a device — a headset's HID protocol has no microphone command (GearLink mutes through Windows too). `list` feeds the Settings dropdown; `Settings.microphone_device` picks one, `None` = the one Windows uses for calls. `level`/`set_level` and `Meter` (#427): a meter opens a shared capture stream (Windows meters an endpoint only while something records) and closes it 1 s after the last `level()` read
- **`profile_rules.rs`** — app rules (#307): `AppRule`, pure `RuleEngine::tick` (settle; in front, then last started, decides; the next one's profile or the one from before after a grace period; a manual pick sets aside the programs running then until they close; one started later still switches); fed by `src-egui/src/app_rules.rs`
- **`desktop_background.rs`** — a profile's desktop background (#306): `DesktopBackground` (picture, or one per screen, + `Fit`), pure `step` (keep Windows' own the first time, put it back in a profile without one), `screens`/`current`/`show` via `IDesktopWallpaper` (COM)
- **`wallpaper_engine.rs`** — Wallpaper Engine per profile (#306): `WeChoice` (pause, or a wallpaper per screen), pure `step`/`prune`, `find`/`Install::library`/`config` (monitormap → screen numbers)/`send` (its `-control` command line)/`launch`, `is_running`, `store_link`, `diagnostics`
- **`settings.rs`** — `Settings` struct + JSON persistence to `%APPDATA%\se.codeby.rigstats\`
- **`debug.rs`** — `log_debug`/`log_warn`/`log_error`; `reset_debug_log` rotates log to `rigstats-debug-prev.log`; `install_panic_logger` (both binaries: every panic → log with thread, file:line, backtrace); `supervise` restarts `poll_loop`/`control_task` after a panic (2 s, doubling to 60 s). The sidecar logs unhandled exceptions, start failures and unexpected pipe errors with stack traces; both logs use local time (sidecar with UTC offset) (#219)
- **`autostart.rs`** — HKCU run key for launch-at-startup
