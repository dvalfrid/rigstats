Your rig.
Always in view.

Real-time hardware monitoring built for a dedicated secondary display — portrait or landscape — scatter individual panels freely in floating mode, or overlay a compact, click-through FPS-style strip directly on top of your game. CPU, GPU, RAM, network, disk, NVMe/SSD temperatures, motherboard sensors, live process monitor, and a built-in multi-GPU selector for stable tracking. The Control Center adds fan curves, power profiles, Ryzen and Radeon power tuning, RGB lighting, and the settings of ROG headsets and mice.

Download View on GitHub →

  • Portrait & landscape layouts

    Designed for 450 × 1920 vertical side displays, with matching landscape profiles (e.g. 1920 × 450) that pack the panels into an adaptive grid. Multiple display profiles fit different monitor sizes and auto-target the right screen.

  • Deep sensor data

    LibreHardwareMonitor provides per-core clocks, GPU hot-spot, memory clock, VRAM, fan RPM, and D3D engine workloads — not just OS counters.

  • Stable multi-GPU view

    When your system has both iGPU and dGPU, use the GPU panel selector to pin exactly which device should be shown.

  • Auto-detected hardware

    CPU model, GPU name, RAM spec, and system brand logo are all detected at startup with no manual config.

  • No telemetry

    All data stays on your machine. No accounts, no cloud, no background uploads. Ever.

  • Temperature alerts

    Configurable warning and critical thresholds for CPU, GPU, RAM, and disk. Windows tray notifications fire when a component runs hot — with a cooldown to prevent spam.

  • Silent auto-updates

    Checks for new versions in the background every 6 hours. A badge in the header lets you update with one click — no manual download required.

  • Floating panel layout

    Switch to floating mode and each panel becomes a draggable, always-on-top window you can place anywhere on any screen. Positions persist across restarts.

  • Session recording & history

    Start and stop recording sessions straight from the tray menu — the tray icon blinks while one is live. Browse, chart, rename, pin, and delete past sessions in the History window.

  • Redesigned tray menu

    Every tray menu row has its own procedurally-drawn icon — no bundled images — with a blinking red dot on Stop Recording while a session is live.

  • Game overlay mode

    A compact, click-through metric strip that sits over any fullscreen game or app. Corner-anchored or free-dragged, with a global Ctrl+Alt+O hotkey to show or hide it without alt-tabbing.

  • Wireless battery at a glance

    Battery level and charging of your wireless headset, keyboard and mouse — and whether each is on USB, Bluetooth or 2.4 GHz — in a dashboard panel and a hover card over the tray icon, with a notification when one runs low. Supported devices.

  • Control Center & fan curves

    Switch between Silent, Balanced, Gaming and Eco profiles from the tray, and give every fan its own curve — evaluated by the service, so it keeps working with the app closed. On Ryzen 9000 they can also lower the CPU power limits and undervolt with Curve Optimizer, on AMD Radeon and desktop NVIDIA GeForce cards set the GPU power limit, and set the lighting — ASUS Aura, ROG peripherals and Philips Hue room lights. ROG headsets get sidetone and noise reduction, ROG mice DPI, polling rate and button bindings — and each profile can pick one of the mouse's own profiles.

Desktop Wallpaper Mode

Mount the dashboard directly into the Windows desktop layer — permanently visible on your primary monitor, never overlapping your apps or taskbar.

  • Behind everything, always visible

    Runs in the Windows WorkerW layer — the same layer as your desktop wallpaper. Visible in any gaps between windows and on empty desktop space, without covering anything.

  • Survives Win+D

    Press Win+D to show the desktop and the dashboard stays put — unlike Always Behind mode, the WorkerW layer is not affected by the Show Desktop command.

  • Separate process, zero focus impact

    The wallpaper host (rigstats-wallpaper) runs isolated from the main app. It never appears in Alt+Tab, never steals focus, and exits automatically when the parent stops.

  • Settings apply on Save

    Because the host is a separate process, changes can't be previewed live. Settings apply on Save, and the display profile is locked while in wallpaper mode — switch layer to change it.

Game Overlay Mode

An FPS-style, click-through overlay that floats over any fullscreen game or app — no alt-tabbing, no separate monitor required. Pick which metrics to show, anchor a corner or drag it anywhere, and toggle it on or off with a global hotkey.

  • Corner-anchored (drag-free) or free-dragged anywhere on screen
  • Choose which metrics appear and reorder them with arrows — per profile, so Gaming can show more than Quiet
  • Adjustable scale, opacity, and an optional frosted background card
  • Click-through by default — mouse clicks pass to the game underneath
  • Global Ctrl+Alt+O hotkey shows/hides it without leaving the game
  • Global Ctrl+Alt+M mutes or unmutes your microphone — from the tray too
  • Every shortcut can be changed or turned off in Settings → Shortcuts, and the tray menu's actions (desk lamp, Control Center, Settings, Status, recording, overlay lock) can get one tooComing in v1.52.0
  • Toggle from the tray menu or the Control Center — independent of window layer or floating mode

Control Center — Profiles, Fans, Lighting, Mouse & Desktop

Profiles bundle your power plan and fan curves — and on supported hardware, CPU and GPU power limits and RGB lighting — together with how RIGStats itself looks: accent colour, panels, overlay and alert levels. They switch with one click from the tray. Fan curves run inside the RIGStats service, so they keep working with the app closed and come back after a reboot.

Profiles

A profile bundles everything at once: power plan, fans, limits, lighting, the desktop and how RIGStats looks.

  • Silent, Balanced, Gaming, Eco — and your own: duplicate, rename and delete them
  • Overview shows everything a profile does at a glance; each tile opens its page
  • Choose the Windows power plan each profile switches to

Switch in one click — or let your apps do it

From the tray, the dashboard's header chip, Ctrl+Alt+P, or straight to one with Ctrl+Alt+F1–F9 — bind a macro key to it in your keyboard's software.

  • App rules switch profile by themselves while a program runs — Gaming while your game is open, back when it closes; optionally only while it is in front
  • A profile you pick by hand wins over the programs already running

How RIGStats looks

Each profile has its own dashboard look, previewed live as you change it.

  • Accent colour, opacity, and which panels show in what order
  • Each panel full or compactComing in v1.52.0
  • Floating panels or the fixed dashboard, and the panels' sizeComing in v1.52.0
  • The game overlay and its metrics
  • Alert levels — Gaming can run hotter before it warns

Your desktop, per profile

A calm picture for Silent, a live wallpaper for Balanced — and nothing running in the background while you game.

  • Desktop background per profile — one picture, or one per screen, with previews
  • Wallpaper Engine per profile: chosen wallpapers per screen, paused while you game, or off in a profile of its own — with Start and Stop right there

Fan curves

Shown when your motherboard exposes writable fan control. Curves run inside the RIGStats service, so they keep working with the app closed. No Armoury Crate needed — and if its fan service is running, RIGStats says so and leaves the fans to it rather than fight over them.

  • Per-fan curves with draggable points, following CPU, GPU or a motherboard temperature
  • Same curve on runs several fans on one curve
  • Identify spins a fan channel and measures which fans respond — channel and fan numbers don't always match
  • Click a fan in the Motherboard panel to open its curve
  • Safety in the service: CPU above 95 °C or GPU above 90 °C sends every controlled fan to 100 %, and a lost temperature sensor does the same for its fan; stopping the service hands every fan back to the BIOS

CPU power limits

AMD Ryzen 9000 — never above what the BIOS set.

  • Lower PPT, TDC and EDC per profile, with 105 W and 65 W Eco presets
  • New limits are tried for 15 seconds and revert by themselves unless you click Keep; if the PC goes down right after a change, they aren't re-applied at the next start
  • Curve Optimizer: undervolt all cores or each core, −30 to 0 — reverted at the next start if the PC goes down right after a change
  • The CPU panel shows the active limit, e.g. PPT 88 W

Graphics card power limit

AMD Radeon and desktop NVIDIA GeForce.

  • The same setting as Adrenalin's or Afterburner's Power Limit, over the driver's own range — and back to the driver default when you return to the original
  • The GPU panel shows the active limit, e.g. PL -15 %

Lighting with Aura Sync

No Armoury Crate needed — if it or OpenRGB is running, RIGStats says so and leaves the lights to it.

  • Off, static, breathing or spectrum cycle per profile, with colour (or one-click quick-pick colours) and brightness and a live preview
  • Desk lamp: the Aura Monitor Light Bar's white lamp gets its own on/off, brightness and colour temperature (2700–6500 K) per profile, independent of the RGB

ROG mice — without Armoury Crate

Everything is kept in the mouse itself, so it works on any PC afterwards. Each profile picks one of the mouse's own onboard profiles — low DPI and 500 Hz for work, high polling for games. Supported mice.

  • DPI levels as chips, with one slider for the level in use
  • Polling rate, button response, lift-off distance, angle snapping, acceleration and motion sync
  • Button bindings on a drawing of the mouse — hover a choice and its button lights up
  • Energy: auto power-off and the mouse's own low-battery warning
  • Wired, on its dongle or on the ROG Omni receiver; only the commands GearLink itself sends, every change read back

Headset and microphone

ROG Delta II and Pelta — no GearLink needed. Supported headsets.

  • Sidetone: hear your own voice during calls, with its level
  • Noise reduction on the microphone — Low, Medium or High
  • Ctrl+Alt+M mutes the microphone from anywhere, shown in the tray and on the dashboard; its level and a live meter are in Settings

Your devices — and Philips Hue

ASUS Aura motherboards, ROG monitors and the Aura Monitor Light Bar, ROG keyboards and headsets, and any Windows Dynamic Lighting keyboard or mouse — full list below.

  • Philips Hue rooms and zones you choose follow along through the Hue Bridge on your local network — no OpenRGB, no Hue account
  • Wireless devices show their connection and battery
  • Devices plugged in or switched between cable and dongle are picked up while RIGStats runs

Thirteen Live Panels (7 default + 6 optional)

Each panel tracks exactly what matters for that component — with sparkline history so you see trends, not just a snapshot.

CPU

Total load history with a sparkline, per-core load bars, current clock frequency, package temperature, and power draw.

  • Total & per-core load (%)
  • Clock frequency (GHz)
  • Package temperature (°C)
  • Package power (W)
sysinfo · LHM

GPU

Core load, temperatures, clocks, power, VRAM, and fan load. D3D engine workload breakdown shows when the GPU is rendering 3D or decoding video. Includes a multi-GPU selector so you can pin a specific GPU instead of auto-switching each tick.

  • Core load (%)
  • Core, hot-spot & VRAM temperature (°C)
  • Core clock (GHz)
  • Package power (W) & fan load (%)
  • VRAM load (%)
  • D3D 3D & Video Decode load (when active)
  • GPU selector for iGPU/dGPU pinning
LHM

RAM

Current usage alongside the full memory spec read directly from BIOS — type, speed, stick identification, and live DDR5/DDR4 temperature.

  • Used / free / total (GB)
  • Memory type (DDR4 / DDR5)
  • Speed (MT/s)
  • Manufacturer & part number
  • DIMM temperature (°C) — DDR5 and equipped DDR4
sysinfo · WMI · LHM

Network

Live upload and download throughput for the best active interface, plus LAN gateway and WAN latency. Upload and download are shown as separate coloured series in the sparkline.

  • Upload / download (Kbps / Mbps)
  • Active interface name
  • LAN & WAN ping (ms)
sysinfo

Storage

Aggregated read and write throughput across your primary drives, plus per-drive capacity, usage, and live NVMe/SSD temperature. Read and write are shown as separate coloured series in the sparkline with matching coloured labels.

  • Read / write throughput (KB/s / MB/s)
  • Per-drive capacity & usage
  • Drive letter & model name
  • Drive temperature (°C)
LHM · sysinfo

Motherboard

Super I/O chip sensors for the full board — all active fan channels, board temperatures, and key voltage rails. Board name and chip model auto-detected at startup. Optional panel, switched on per profile in the Control Center.

  • Fan channels (RPM) — all active, sorted by speed
  • Board temperatures (°C) — unnamed slots shown as T1–T6
  • Voltage rails — Vcore, AVCC, +3.3V, CPU Termination, and more
  • Motherboard name & Super I/O chip model
LHM · WMI

Processes

A miniature Task Manager always visible on the portrait display. Shows the top 8 processes sorted by CPU usage so you can instantly see which game, encoder, or background service is consuming your hardware. Optional panel, switched on per profile in the Control Center.

  • Top 8 processes by CPU usage
  • Per-process CPU % of total system capacity
  • Per-process RAM usage (MB / GB)
sysinfo

GPU Apps

Task-Manager-style per-process GPU usage — see exactly which game, encoder, or background app is actually using the GPU, not just overall load. Attributes each process to a physical adapter when more than one GPU is active. Optional panel, switched on per profile in the Control Center.

  • Top processes by GPU usage (%)
  • Engine type per process (3D, Video Decode, etc.)
  • Physical adapter attribution on multi-GPU systems
PDH

Battery

Live battery status for gaming laptops. Shows charge percentage, charging/discharging state, estimated time remaining, and live power draw. Optional panel; shows "NO BATTERY" gracefully on desktop systems.

  • Charge percentage (0–100 %)
  • Status: CHARGING or DISCHARGING
  • Estimated time remaining
  • Live power draw (W) — charge rate when plugged in, discharge rate on battery
  • Color-coded bar: green / amber / red by charge level
  • Color-coded power against configurable warn/critical thresholds (15 W / 25 W by default)
WMI

Peripherals

Battery levels of your wireless gear at a glance — ROG headsets, ROG keyboards and mice on the ROG Omni receiver, and any Bluetooth mouse, keyboard or headset that reports its battery to Windows — read by the background service every 20 seconds. Optional panel, switched on per profile in the Control Center.

  • Battery level (%) per device
  • Charging state
  • Connection icon: USB, Bluetooth or 2.4 GHz
  • A device that disconnects is greyed out at once, with its last level
  • Color-coded bar using the Battery panel's thresholds
  • Also without opening anything: hover the RIGStats tray icon
Sensor service

System Power

Estimated total system power draw with a CPU/GPU/Other breakdown, so you can see at a glance what your rig is pulling from the wall. Optional panel, switched on per profile in the Control Center.

  • Estimated total draw (~W) — CPU Package + GPU Package + platform overhead
  • Proportional breakdown bars: CPU (cyan), GPU (red), Other (platform overhead)
  • Bottom gauge scaled to your PSU's rated wattage — set it once in Settings
  • Auto-reference (500 W desktop / 120 W laptop) when no PSU wattage is configured
  • Dims gracefully when LHM sensors are unavailable
LHM

Clock

Current time, day, and date displayed cleanly at the top of the dashboard — always visible at a glance.

  • Time (HH:MM:SS)
  • Day of week & date
  • System uptime
sysinfo

System Identity

System brand, hostname, and model name auto-detected at startup. Recognized gaming OEMs — ROG, MSI, Alienware, Legion, OMEN, Razer, Predator, AORUS — display their brand logo automatically.

  • Hostname / rig name
  • System brand & model name
  • Brand logo (auto-detected)
WMI · sysinfo

Data sources

  • LHMLibreHardwareMonitor — kernel-level sensor data (CPU/GPU temps, clocks, power, fan speeds) read via the bundled sensor service
  • sysinfoRust sysinfo crate — OS metrics (CPU load, RAM, disk I/O, network, processes) read directly without a kernel driver
  • WMIWindows Management Instrumentation — system identity data (GPU model, RAM spec, motherboard, battery) queried at startup

Common questions

My ASUS / ROG mouse or keyboard is listed in the Control Center, but doesn't change colour

The device has its own lighting mode, saved in the device, that decides whether it follows lighting commands from outside. For the ROG mice that have it on the ROG Omni receiver (Harpe Ace Aim Lab Edition, Keris II Ace, Harpe Ace Mini, Harpe Ace Extreme), the Control Center's Lighting tab reads the setting and offers a Let RIGStats control it button. For other devices, open Gear Link (older firmware needs its Gear Link Companion app) or Armoury Crate and set the device's Cross-device Lighting Toggle to Aura Sync & Windows Dynamic Lighting. In "Device Lighting" mode it ignores every change — RIGStats can't detect that, because the device doesn't report its colour back.

The setting stays in the device, so Gear Link or Armoury Crate can be closed or uninstalled afterwards. Keep Windows' own Use Dynamic Lighting on my devices turned off, otherwise RIGStats leaves the device to Windows.

The Control Center says "Refused by the service", or changes don't apply

The rigstats-sensor service must be running. Only the installed, signed RIGStats may control hardware — a copied or self-built rigstats.exe is refused by design.

AMD graphics: the sensor service keeps stopping, or the update fails with "Error opening file for writing … rigstats-sensor.exe"

Windows Update can replace the driver that AMD Software (Adrenalin) installed with an older one. The driver's parts then no longer fit together: AMD Software says "Update Required" when you open it, and RIGStats' sensor service stops every time RIGStats starts, because AMD's driver library (ADLX) crashes when it is asked about the graphics card. Windows restarts the service a few times and then gives up, and while it keeps restarting, a RIGStats update can't replace the service's file. Seen in October 2026, after Windows Update installed "AMD Display Driver Update (32.0.21042.62)".

Fix:

  1. Open AMD Software. If it says "Update Required", click Download & Install (or download the latest driver from amd.com) and restart if it asks.
  2. Restart Windows, or start the service from a terminal opened as administrator: sc start rigstats-sensor.
  3. If a RIGStats update failed, run the installer again.

To keep it from happening again, stop Windows from replacing drivers on its own: Settings → System → About → Advanced system settings → Hardware → Device Installation Settings → No. Security updates still install as usual.

From version 1.48.1 the service keeps running even if a graphics driver crashes: the Control Center's Graphics card page then says what happened, with a button for the driver download and Collect diagnostics… (#370). Still stuck? Open an issue with a diagnostics ZIP (Status → Collect Diagnostics).
