Your rig.
Always in view.

Real-time hardware monitoring built for a dedicated secondary display — portrait or landscape — scatter individual panels freely in floating mode, or overlay a compact, click-through FPS-style strip directly on top of your game. CPU, GPU, RAM, network, disk, NVMe/SSD temperatures, motherboard sensors, live process monitor, and a built-in multi-GPU selector for stable tracking. The Control Center adds fan curves, power profiles, Ryzen and Radeon power tuning, and RGB lighting.

  • Portrait & landscape layouts

    Designed for 450 × 1920 vertical side displays, with matching landscape profiles (e.g. 1920 × 450) that pack the panels into an adaptive grid. Multiple display profiles fit different monitor sizes and auto-target the right screen.

  • Deep sensor data

    LibreHardwareMonitor provides per-core clocks, GPU hot-spot, memory clock, VRAM, fan RPM, and D3D engine workloads — not just OS counters.

  • Stable multi-GPU view

    When your system has both iGPU and dGPU, use the GPU panel selector to pin exactly which device should be shown.

  • Auto-detected hardware

    CPU model, GPU name, RAM spec, and system brand logo are all detected at startup with no manual config.

  • No telemetry

    All data stays on your machine. No accounts, no cloud, no background uploads. Ever.

  • Temperature alerts

    Configurable warning and critical thresholds for CPU, GPU, RAM, and disk. Windows tray notifications fire when a component runs hot — with a cooldown to prevent spam.

  • Silent auto-updates

    Checks for new versions in the background every 6 hours. A badge in the header lets you update with one click — no manual download required.

  • Floating panel layout

    Switch to floating mode and each panel becomes a draggable, always-on-top window you can place anywhere on any screen. Positions persist across restarts.

  • Session recording & history

    Start and stop recording sessions straight from the tray menu — the tray icon blinks while one is live. Browse, chart, rename, pin, and delete past sessions in the History window.

  • Redesigned tray menu

    Every tray menu row has its own procedurally-drawn icon — no bundled images — with a blinking red dot on Stop Recording while a session is live.

  • Game overlay mode

    A compact, click-through metric strip that sits over any fullscreen game or app. Corner-anchored or free-dragged, with a global Ctrl+Alt+O hotkey to show or hide it without alt-tabbing.

  • Control Center & fan curves

    Switch between Silent, Balanced, Gaming and Eco profiles from the tray, and give every fan its own curve — evaluated by the service, so it keeps working with the app closed. On Ryzen 9000 they can also lower the CPU power limits and undervolt with Curve Optimizer, on AMD Radeon and desktop NVIDIA GeForce cards set the GPU power limit, and set the lighting — ASUS Aura, ROG peripherals and Philips Hue room lights.

Three Display Modes

Portrait fills a dedicated vertical display; landscape arranges the same panels in an adaptive grid on a wide screen. Floating mode lets you place each panel wherever it fits — on your gaming monitor, your side screen, or anywhere between.

  • Each panel is an independent frameless window
  • Drag any panel to reposition it — positions are saved across restarts
  • Click the padlock on a panel's drag handle to lock its position and prevent accidental moves
  • Scale all floating panels from 40% to 100% in Settings
  • Panel visibility follows the same settings as portrait mode
  • Toggle floating mode from Settings or the tray menu

Desktop Wallpaper Mode

Mount the dashboard directly into the Windows desktop layer — permanently visible on your primary monitor, never overlapping your apps or taskbar.

  • Behind everything, always visible

    Runs in the Windows WorkerW layer — the same layer as your desktop wallpaper. Visible in any gaps between windows and on empty desktop space, without covering anything.

  • Survives Win+D

    Press Win+D to show the desktop and the dashboard stays put — unlike Always Behind mode, the WorkerW layer is not affected by the Show Desktop command.

  • Separate process, zero focus impact

    The wallpaper host (rigstats-wallpaper) runs isolated from the main app. It never appears in Alt+Tab, never steals focus, and exits automatically when the parent stops.

  • Settings apply on Save

    Because the host is a separate process, changes can't be previewed live. Settings apply on Save, and the display profile is locked while in wallpaper mode — switch layer to change it.

Game Overlay Mode

An FPS-style, click-through overlay that floats over any fullscreen game or app — no alt-tabbing, no separate monitor required. Pick which metrics to show, anchor a corner or drag it anywhere, and toggle it on or off with a global hotkey.

  • Corner-anchored (drag-free) or free-dragged anywhere on screen
  • Choose which metrics appear and reorder them with arrows
  • Adjustable scale, opacity, and an optional frosted background card
  • Click-through by default — mouse clicks pass to the game underneath
  • Global Ctrl+Alt+O hotkey shows/hides it without leaving the game
  • Toggle from the tray menu or Settings — independent of window layer or floating mode

Recording, Right From the Tray

Every menu row now has its own procedurally-drawn icon — no external image assets — and starting a recording is one click away.

  • Toggle Start/Stop Recording from the tray menu — no dialog needed
  • The tray icon blinks a red dot while a session is live, so it's obvious at a glance
  • Open Session History from the same menu to browse and chart past sessions
  • Toggle Overlay Mode and Lock Overlay (click-through) rows show/hide and lock the game overlay without opening Settings
  • Toggle Desk Lamp switches the ROG Aura Monitor Light Bar's desk lamp off and back on — shown only when one is connected
  • Every menu row's icon is drawn procedurally at startup — no bundled image assets
  • Profile switches the active Control Center profile, and Control Center… opens it

Control Center & Fan Curves

Profiles bundle your power plan and fan curves — and on supported hardware, CPU and GPU power limits —, and switch with one click from the tray. Fan curves run inside the RIGStats service, so they keep working with the app closed and come back after a reboot.

  • Silent, Balanced, Gaming, Eco — switch from the tray, the header chip, or Ctrl+Alt+P
  • Duplicate, rename and delete your own profiles; choose the Windows power plan each profile switches to
  • Per-fan curves with draggable points, following CPU, GPU or a motherboard temperature
  • Same curve on runs several fans on one curve
  • Identify spins a fan channel and measures which fans respond — channel and fan numbers don't always match
  • Click a fan in the Motherboard panel to open its curve
  • Safety in the service: CPU above 95 °C or GPU above 90 °C sends every controlled fan to 100 %, and a lost temperature sensor does the same for its fan
  • Stopping the service hands every fan back to the BIOS
  • Shown only when your motherboard exposes writable fan control
  • CPU power limits (AMD Ryzen 9000): lower PPT, TDC and EDC per profile, with 105 W and 65 W Eco presets — never above what the BIOS set
  • New limits are tried for 15 seconds and revert by themselves unless you click Keep; if the PC goes down right after a change, the limits aren't re-applied at the next start
  • The CPU panel shows the active limit, e.g. PPT 88 W
  • Curve Optimizer (Ryzen 9000): undervolt all cores or each core, −30 to 0 — and if the PC goes down right after a change, it is reverted at the next start
  • GPU power limit (AMD Radeon, desktop NVIDIA GeForce): the same setting as Adrenalin's or Afterburner's Power Limit, over the driver's own range — and back to the driver default when you return to the original
  • The GPU panel shows the active limit, e.g. PL -15 %
  • Lighting with Aura Sync: off, static, breathing or spectrum cycle per profile, with colour (or one-click quick-pick colours) and brightness and a live preview — on ASUS Aura motherboards, ROG monitors and the Aura Monitor Light Bar, ROG keyboards and headsets, and any Windows Dynamic Lighting keyboard or mouse (full list below) — no Armoury Crate needed. Philips Hue rooms and zones you choose follow along through the Hue Bridge on your local network — no OpenRGB, no Hue account. Devices plugged in or switched between cable and dongle are picked up while RIGStats runs
  • Desk lamp: the Aura Monitor Light Bar's white lamp gets its own on/off, brightness and colour temperature (2700–6500 K) per profile, independent of the RGB

Twelve Live Panels (7 default + 5 optional)

Each panel tracks exactly what matters for that component — with sparkline history so you see trends, not just a snapshot.

CPU

Total load history with a sparkline, per-core load bars, current clock frequency, package temperature, and power draw.

  • Total & per-core load (%)
  • Clock frequency (GHz)
  • Package temperature (°C)
  • Package power (W)
sysinfo · LHM

GPU

Core load, temperatures, clocks, power, VRAM, and fan load. D3D engine workload breakdown shows when the GPU is rendering 3D or decoding video. Includes a multi-GPU selector so you can pin a specific GPU instead of auto-switching each tick.

  • Core load (%)
  • Core temperature & hot-spot (°C)
  • Core clock (GHz)
  • Package power (W) & fan load (%)
  • VRAM load (%)
  • D3D 3D & Video Decode load (when active)
  • GPU selector for iGPU/dGPU pinning
LHM

RAM

Current usage alongside the full memory spec read directly from BIOS — type, speed, stick identification, and live DDR5/DDR4 temperature.

  • Used / free / total (GB)
  • Memory type (DDR4 / DDR5)
  • Speed (MT/s)
  • Manufacturer & part number
  • DIMM temperature (°C) — DDR5 and equipped DDR4
sysinfo · WMI · LHM

Network

Live upload and download throughput for the best active interface, plus LAN gateway and WAN latency. Upload and download are shown as separate coloured series in the sparkline.

  • Upload / download (Kbps / Mbps)
  • Active interface name
  • LAN & WAN ping (ms)
sysinfo

Storage

Aggregated read and write throughput across your primary drives, plus per-drive capacity, usage, and live NVMe/SSD temperature. Read and write are shown as separate coloured series in the sparkline with matching coloured labels.

  • Read / write throughput (KB/s / MB/s)
  • Per-drive capacity & usage
  • Drive letter & model name
  • Drive temperature (°C)
LHM · sysinfo

Motherboard

Super I/O chip sensors for the full board — all active fan channels, board temperatures, and key voltage rails. Board name and chip model auto-detected at startup. Optional panel, enabled in Settings.

  • Fan channels (RPM) — all active, sorted by speed
  • Board temperatures (°C) — unnamed slots shown as T1–T6
  • Voltage rails — Vcore, AVCC, +3.3V, CPU Termination, and more
  • Motherboard name & Super I/O chip model
LHM · WMI

Processes

A miniature Task Manager always visible on the portrait display. Shows the top 8 processes sorted by CPU usage so you can instantly see which game, encoder, or background service is consuming your hardware. Optional panel, enabled in Settings.

  • Top 8 processes by CPU usage
  • Per-process CPU % of total system capacity
  • Per-process RAM usage (MB / GB)
sysinfo

GPU Apps

Task-Manager-style per-process GPU usage — see exactly which game, encoder, or background app is actually using the GPU, not just overall load. Attributes each process to a physical adapter when more than one GPU is active. Optional panel, enabled in Settings.

  • Top processes by GPU usage (%)
  • Engine type per process (3D, Video Decode, etc.)
  • Physical adapter attribution on multi-GPU systems
PDH

Battery

Live battery status for gaming laptops. Shows charge percentage, charging/discharging state, estimated time remaining, and live power draw. Optional panel; shows "NO BATTERY" gracefully on desktop systems.

  • Charge percentage (0–100 %)
  • Status: CHARGING or DISCHARGING
  • Estimated time remaining
  • Live power draw (W) — charge rate when plugged in, discharge rate on battery
  • Color-coded bar: green / amber / red by charge level
  • Color-coded power against configurable warn/critical thresholds (15 W / 25 W by default)
WMI

System Power

Estimated total system power draw with a CPU/GPU/Other breakdown, so you can see at a glance what your rig is pulling from the wall. Optional panel, enabled in Settings.

  • Estimated total draw (~W) — CPU Package + GPU Package + platform overhead
  • Proportional breakdown bars: CPU (cyan), GPU (red), Other (platform overhead)
  • Bottom gauge scaled to your PSU's rated wattage — set it once in Settings
  • Auto-reference (500 W desktop / 120 W laptop) when no PSU wattage is configured
  • Dims gracefully when LHM sensors are unavailable
LHM

Clock

Current time, day, and date displayed cleanly at the top of the dashboard — always visible at a glance.

  • Time (HH:MM:SS)
  • Day of week & date
  • System uptime
sysinfo

System Identity

System brand, hostname, and model name auto-detected at startup. Recognized gaming OEMs — ROG, MSI, Alienware, Legion, OMEN, Razer, Predator, AORUS — display their brand logo automatically.

  • Hostname / rig name
  • System brand & model name
  • Brand logo (auto-detected)
WMI · sysinfo

Data sources

  • LHMLibreHardwareMonitor — kernel-level sensor data (CPU/GPU temps, clocks, power, fan speeds) read via the bundled sensor service
  • sysinfoRust sysinfo crate — OS metrics (CPU load, RAM, disk I/O, network, processes) read directly without a kernel driver
  • WMIWindows Management Instrumentation — system identity data (GPU model, RAM spec, motherboard, battery) queried at startup

Five Supporting Dialogs

Accessible from the system tray icon. Each dialog has a single, focused purpose.

Settings

Six focused tabs to configure every aspect of the dashboard. Changes apply as a live preview; Cancel restores the previous state. In Desktop Wallpaper mode the dashboard is a separate background process, so settings apply on Save instead of live preview, no-op controls grey out, and the display profile is locked — switch to a non-wallpaper layer to change it.

  • Display — display profile, window layer (Normal / Always on Top / Always Behind / Desktop Wallpaper — lives in the wallpaper layer and survives Win+D), opacity, floating mode and panel scale, fill screen and alignment
  • Panels — toggle panel visibility, use arrows to reorder, set PSU rated wattage
  • Alerts — Notify on Critical toggle, cooldown, Warn/Crit thresholds for CPU/GPU/RAM/Disk temperature (°C), CPU/GPU/RAM/Disk usage (%), and battery charge % and power W
  • Appearance — override model name, colour theme
  • General — launch at startup, stats CSV logging and retention
  • Overlay — enable the game overlay, choose and reorder metrics, columns/anchor/scale/opacity/background, click-through lock

Status

Runtime health view for every data source. Shows the rigstats-sensor Windows Service state, dependency health indicators, GPU driver versions with age warnings, the live debug log, and last successful refresh time.

  • Dependency health indicators (sensor, sysinfo, WMI)
  • GPU driver version & age per adapter
  • Live debug log viewer with Copy Log button
  • Last successful refresh timestamp
  • Diagnostics ZIP export

Session History

Browse and chart past recording sessions. Each session gets its own CPU/GPU/RAM/network/disk/ping charts with synced hover, so you can see exactly what happened during a gaming session or stress test.

  • Pin, rename, reveal in Explorer, or delete any session
  • Synced multi-chart hover — one moment in time across every metric
  • Avg/peak summary tiles per session
  • Automatic retention pruning; pinned sessions are always kept

Download & Install

A single NSIS installer handles everything — including setting up the LibreHardwareMonitor sensor as a Windows Service so sensor data is available immediately at startup.

Requirements

  • ✓ Windows 10 or 11 (64-bit)
  • ✓ Administrator rights during installation
  • ✓ A secondary portrait display is recommended but not required

Having a Problem?

RIGStats has a built-in diagnostics export that captures everything needed to investigate sensor or hardware compatibility issues.

    Open the Status dialog

    Attach the ZIP when reporting

Common questions

My ASUS / ROG mouse or keyboard is listed in the Control Center, but doesn't change colour

The device has its own lighting mode, saved in the device, that decides whether it follows lighting commands from outside. For the ROG mice that have it on the ROG Omni receiver (Harpe Ace Aim Lab Edition, Keris II Ace, Harpe Ace Mini, Harpe Ace Extreme), the Control Center's Lighting tab reads the setting and offers a Let RIGStats control it button. For other devices, open Gear Link (older firmware needs its Gear Link Companion app) or Armoury Crate and set the device's Cross-device Lighting Toggle to Aura Sync & Windows Dynamic Lighting. In "Device Lighting" mode it ignores every change — RIGStats can't detect that, because the device doesn't report its colour back.

The setting stays in the device, so Gear Link or Armoury Crate can be closed or uninstalled afterwards. Keep Windows' own Use Dynamic Lighting on my devices turned off, otherwise RIGStats leaves the device to Windows.

The Control Center says "Not connected" or changes don't apply

The rigstats-sensor service must be running. Only the installed, signed RIGStats may control hardware — a copied or self-built rigstats.exe is refused by design.
